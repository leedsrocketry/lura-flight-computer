# Custom Flight Computer

Primary avionics, tracking, and telemetry, built for ESP32.

## Layout

| Crate | Runs on | Purpose |
|---|---|---|
| `proto/` | both | Shared `no_std` code: message types, encoding, CRC |
| `onboard/` | ESP32-S3 | Flight firmware (bare-metal Rust, Embassy async) |
| `ground/` | your computer | Ground station: receives and decodes telemetry |

`proto` and `ground` form a Cargo workspace at the repository root. `onboard` is kept out of the workspace because it uses the `esp` toolchain and builds for the `xtensa-esp32s3-none-elf` target; build it from inside `onboard/`.

## Dev container

`.devcontainer/` contains a ready-made environment with stable Rust, the ESP Xtensa toolchain, and espflash. Open the repository in VS Code with the Dev Containers extension and choose **Reopen in Container** (Docker must be running). The first build of the image takes several minutes.

Inside the container everything builds as described below, without the `export-esp.sh` step.

**Flashing from the container:** Docker Desktop on macOS and Windows cannot pass USB devices into containers. Build inside the container, then flash from a terminal on your computer (this needs espflash installed there):

```sh
espflash flash --monitor onboard/target/xtensa-esp32s3-none-elf/release/onboard
```

On a Linux host, uncomment `runArgs` in `.devcontainer/devcontainer.json` to give the container your serial ports, and `cargo run --release` will flash directly.

## Manual setup

Install Rust, then install the ESP Xtensa toolchain and flashing utility:

```sh
cargo install espup --locked
espup install
cargo install espflash --locked
```

On macOS and Linux, load the environment generated by espup in each shell (the installer prints its path), for example:

```sh
. "$HOME/export-esp.sh"
```

## Onboard firmware

Connect an ESP32-S3 development board by USB, then build, flash, and open the serial monitor:

```sh
cd onboard
cargo run --release
```

If prompted, select the board's serial port. Use `cargo build --release` to build without flashing.

## Ground station and tests

From the repository root:

```sh
cargo run -p ground
cargo test
```
